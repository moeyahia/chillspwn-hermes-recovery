# Visual direction

Status: engineering direction selected; generated moodboard comparison and production-asset approval pending.

## Direction

Use **Graphite Command Intelligence** as the working visual thesis for `CHILLSPWN // COMMAND OS`:

- near-black graphite foundation with layered neutral surfaces;
- crisp low-chroma borders and controlled depth;
- the existing acid-lime mark/accent used for identity, selected state, live progress, and healthy connection;
- semantic blue for information, amber for Guided decisions/degraded operation, red for failure/destructive risk, and violet only for a documented research/memory meaning;
- high-contrast neutral typography with mono reserved for IDs, commands, hashes, and technical payloads;
- sparse ambient geometry derived from topology/evidence relationships, not hacker imagery.

This direction best supports the requested calm urgency and information density. It is an implementation decision, not evidence that the required three generated moodboards have been completed. `Precision Operations` and `Calm Autonomous Systems` remain comparison briefs for the Higgsfield draft round; production media will be chosen only after scoring clarity, originality, legibility behind UI, provenance, file weight, and reduced-motion behavior.

## Visual hierarchy

1. **Mission truth:** objective, journey, phase, current owner, status, heartbeat, next action.
2. **Needs attention:** a Guided decision, Autonomous safe stop, failure diagnosis, or readiness break receives the strongest weight.
3. **Operational change:** progress/evidence delta and plan/topology selection.
4. **Context:** Brain influence, model/provider, budget, history, and raw technical detail.

Not every region is a rounded card. Use continuous work canvases, master-detail panes, tables, rails, graph surfaces, and restrained inset sections. Primary controls align consistently at the edge of the relevant object.

## Token intent

CSS variables are the source of truth. Tailwind utilities and component variants consume them. Required roles include:

- graphite canvas, elevated surface, selected surface, and technical drawer;
- text primary/secondary/muted/inverse;
- border subtle/default/strong/focus;
- brand/live/success, info, decision/degraded, danger/failure, and research semantics;
- chart/topology categorical roles that remain distinguishable without color alone;
- spacing, density, radii, elevation, z-index, typography scale, motion duration/easing, and touch target.

The acid lime may not become a full-screen glow. Red is reserved for failure or destructive risk. Status always has text plus shape/icon/pattern, not color alone.

## Layout system

- slim global top bar for readiness, search/command palette, connection state, and operator controls;
- collapsible left navigation with the 12 defined product destinations;
- content canvas with route-owned headings and stable mission header where applicable;
- optional contextual intelligence rail on wide screens;
- Commander/technical drawers that do not own durable state;
- tablet drawers and mobile bottom sheets rather than a squeezed three-column desktop layout.

Pause, Guided decision, Autonomous abort, and recovery remain reachable at every supported viewport. Touch targets are at least 44×44 CSS pixels. The layout must survive 200% zoom and long realistic targets, CVEs, errors, and filenames.

## Typography and icons

Use one modern system/grotesk stack for product copy and one highly legible mono stack for technical material. Paragraphs and explanations remain proportional. Type hierarchy distinguishes page, object, status, metadata, and raw detail without relying on all caps.

Use one maintained icon set. Do not use emoji or cyber-glyphs as functional icons in V2. Icons require accessible names through their controls; decorative icons are hidden from assistive technology.

## Motion contract

Motion is short and state-bound:

- event enter and evidence attach;
- ownership/handoff transfer;
- plan-step transition;
- Guided decision block;
- recovery start and safe stop;
- completion.

Only a minimal live pulse may repeat. Hidden tabs suspend nonessential rendering. `prefers-reduced-motion` removes spatial movement and preserves instant state cues. Graph layout occurs off the main thread when expensive.

## Graph and topology language

Graph nodes use shape/pattern plus color by domain and status. Edge emphasis is conditional: dim unrelated links, highlight selected plan/attack/memory paths, and show labels on demand. Unknown topology stays visually unknown; inferred and verified relationships are distinct. Large graphs start clustered and progressively reveal detail with a table/list alternative.

## Generated-media contract

Higgsfield exposed 69 tools and successfully completed the reference-video analysis. On 2026-07-16 the production-asset preflight then returned `OAuth authorization required` for both balance and image-model discovery. No credits were spent and no substitute generator was used, because the requested assets require Higgsfield provenance. The required three 16:9 moodboards, ambient Command Center image, onboarding visual, optional specialist emblems, and empty states therefore remain blocked on Higgsfield re-authorization. When created:

- no logo or text is generated into media;
- source goes under `public/brand-v2/source/`, optimized AVIF/WebP/WebM/MP4 under `public/brand-v2/optimized/`;
- `manifest.json` records prompt, tool/model, date, source, derivatives, dimensions, sizes, placement, alt text, and provenance/license notes;
- operational UI composes the unchanged SVG logo itself;
- all media is lazy, responsive, optional, and absent from the initial operational critical path.

No generated image is a product fixture or source of dashboard truth.
