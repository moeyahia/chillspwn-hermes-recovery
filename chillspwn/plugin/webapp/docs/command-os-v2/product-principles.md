# Product principles

1. Mission state outlives every conversation and provider process.
2. The user chooses only Autonomous or Guided; providers are policy-routed implementation details.
3. Autonomous never requires routine mid-run input. It proceeds in contract, recovers in contract, or safe-stops.
4. Guided never performs a consequential chain behind one vague approval. Each represented action is deliberate and exact.
5. Progress means state, evidence, findings, resolved uncertainty, or deliverables—not merely output.
6. The commander plans, routes, supervises, evaluates, and synthesizes; specialists execute domain work.
7. Every important action explains purpose, result, evidence delta, policy basis, memory context, and next transition.
8. Database state, events, checkpoints, and audit records advance transactionally.
9. Memory is user-owned, scoped, inspectable, correctable, forgettable, and never a hidden profile.
10. Generated media is optional atmosphere. Operational truth remains legible and fast without it.
11. Recovery is an explicit state with bounded alternatives, never a generic spinner.
12. Claims of improvement require comparative evaluation evidence.
