# Visual direction

## Research drafts

Three low-cost 16:9 moodboards were generated with Higgsfield Z Image:

1. Graphite Command Intelligence — rejected because it drifted into code-wall imagery and generated fake text.
2. Precision Operations — rejected because it embedded typography and felt like a static presentation board.
3. Calm Autonomous Systems — selected for its negative space, quiet topology, controlled lime signals, and suitability behind operational UI.

The moodboards are research artifacts under `public/brand-v2/source/`; they are not critical-path UI assets.

Production generation was intentionally limited to one Command Center ambient, one onboarding illustration, and seven operational empty states. Specialist portraits were not generated: fleet identity is clearer and more trustworthy when role, capability, health, and assignment remain the primary recognition system. Source prompts, dimensions, derived AVIF/WebP variants, intended placement, alt text, and provenance are recorded in `public/brand-v2/manifest.json`.

## Selected expression

**Calm Autonomous Systems**

- Near-black graphite foundations and layered neutral surfaces.
- Acid lime only for brand identity, live progress, selection, and healthy connection.
- Semantic blue for information; amber for decisions/degradation; red for failure/destructive risk.
- Thin topology and evidence relationships rather than code walls or fake terminal output.
- Broad quiet regions for readable operational content.
- Crisp borders, subtle depth, restrained radii, and modern grotesk/system typography.
- Motion is reserved for ownership transfer, state transition, recovery, evidence attachment, and completion.
